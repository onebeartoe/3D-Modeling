Model Summary

  Summary of Changes
                                                                                                                            
  1. Generalized Model Layer (MeshModel)                                                                                    
      • Added src/main/java/com/thumbnailer/model/MeshModel.java as the format-agnostic mesh interface (getTriangles(),     
      getBounds(), getTriangleCount(), MeshModel.of(...)).                                                                  
      • Added src/main/java/com/thumbnailer/model/DefaultMeshModel.java and updated                                         
      src/main/java/com/thumbnailer/model/StlModel.java to extend DefaultMeshModel so STL callers stay backwards-compatible 
      with zero duplicated bounds logic.                                                                                    
      • Updated src/main/java/com/thumbnailer/model/Triangle.java to carry an optional per-facet Color while keeping        
      existing 3- and 4-argument constructors intact.
  2. Shared Top-Down Renderer
      • Created src/main/java/com/thumbnailer/renderer/TopDownModelRenderer.java accepting MeshModel and supporting per-    
      triangle colors (falling back to modelColor when null).
      • Simplified src/main/java/com/thumbnailer/renderer/StlModelRenderer.java into a backwards-compatible subclass of     
      TopDownModelRenderer.
  3. Pure-Java .3mf Reader & Unified Dispatcher
      • Added src/main/java/com/thumbnailer/reader/ThreeMfReader.java using JDK ZipFile + StAX (XMLInputFactory with        
      DTD/external entities disabled) to parse:
          • _rels/.rels 3D model discovery (with 3D/3dmodel.model fallback)
          • <mesh> vertices/triangles and <components> + <build> <item> instancing
          • 3x4 affine transform composition, model unit scaling, cyclic reference detection, and Production extension      
          p:path external .model parts
          • <basematerials> and <m:colorgroup> facet/object colors
      • Added src/main/java/com/thumbnailer/reader/ModelReader.java to filter and dispatch .stl and .3mf files.             
  4. CLI, Docs, and Tests
      • Updated src/main/java/com/thumbnailer/Main.java and README.md to process both .stl and .3mf files using ModelReader 
      and TopDownModelRenderer.
      • Added src/test/java/com/thumbnailer/ThreeMfReaderTest.java covering basic .3mf rendering,
      components/transforms/p:path/colorgroup, <basematerials> + centimeter units + instancing + cycle detection, and       
      ModelReader.isSupportedFile.
